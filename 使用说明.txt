内存守护 · 使用说明
================================================================

【怎么启动】
双击桌面上的「内存守护」图标。没有黑窗口，界面直接弹出来。
再点一次不会开第二个，只会把已经打开的窗口叫到最前面。

================================================================
一、主界面怎么看
================================================================

  ● 最上面一行          左边一句状态（「正在守护 · 一切安静」），
                        右边「详细信息 ›」进去看全部程序和历史记录

  ● 大数字              这就是内存占用百分比，是全窗口最显眼的东西。
                        下面是「已用 12.6 GB · 共 15.8 GB」和一条细横条，
                        横条的长度就是占用比例。

  ● 右上角的曲线        最近 5 分钟的内存走势。看它是稳住了还是一路往上涨
                        ——后者才是真正要处理的情况。刚启动时会写「最近 40 秒」
                        这种，意思是才记了这么点时间，凑满 5 分钟就固定了。

  ● 数字右边的两个字    数字右侧会写「内存充足 / 内存偏紧 / 需要释放」，
                        一眼知道要不要管它。平时整个界面是黑白的，
                        只有当占用超过 85% 时，数字、横条和曲线才会变成砖红色提醒你。

  ● 黑色按钮            黑色胶囊「释放内存」，点一下整理一次内存。
                        按钮下方一行小字是这一轮的成绩（释放了多少、关掉几个弹窗）。

  ● 程序列表            标题有两个，点一下就切换：
                        「占用最大」——现在谁占得多；
                        「涨得最快」——这五分钟谁涨得最多。
                        找内存泄漏用后者：占用不高但一直在涨的，才是有问题的那个。

                        列表按"应用"合并显示（豆包开了 20 个进程也只算一行，
                        名字后面标着「19 个进程」）。右边是它占用的内存，
                        内存左边如果出现「↑ 862 MB」，就是这五分钟涨了这么多；
                        涨过 500 MB 会标成砖红色。

                        最右边「结束」点一下会变成「确定？」，
                        3 秒内再点一次才真的关掉——防止手滑。

  ● 最下面的开关        自动拦截弹窗：开着的时候，发现推广弹窗进程会自动关掉

  键盘也能用：Tab 切换「释放 / 开关 / 详细信息」，回车执行，Esc 取消选中。


================================================================
二、它会自己做的事
================================================================

1. 每秒看一眼内存，大数字实时在变；
2. 每 3 秒扫一遍所有程序，命中拦截名单的自动结束，并在下面计数；
3. 内存占用超过 85% 时，自动帮你回收一轮（不用你点）；
   只回收后台进程的工作集，**有可见窗口、你正在用的程序一律跳过**——
   把大程序的内存整个搬走，它得立刻再读回来，中途会卡住甚至自己重启；
4. 所有动作都记录在「详细信息 → 记录」里。

不需要你操作，放着就行。

四、白名单：怎么保证不误删系统进程
================================================================

程序内部有「四道锁」，按顺序检查，任何一条命中就绝不结束：

  ① 系统进程名单     explorer、svchost、lsass、csrss、dwm、winlogon 等
                     67 个 Windows 核心进程，永不结束
  ② 系统目录         C:\Windows 整个目录，以及 WindowsApps、Defender、
                     Common Files\Microsoft Shared 等系统目录里的程序
  ③ 微软签名         可执行文件的版本信息里写着 Microsoft 的程序
  ④ 系统服务         运行在 Session 0（系统服务层）的进程

在这四道锁之外，你还可以自己加「绝对不要动」的东西：

  「详细信息 → 程序 → 已保护」→ 输入框里填 → 点「加入保护」
     · 填程序名：chrome.exe
     · 填目录：  D:\工作软件    （这个目录下的所有程序都保护）

注意：四道锁的优先级高于你的白名单。就算你在白名单里写了 lsass.exe，
      它依然会被保护 —— 这是故意的，防止手滑把系统搞崩。


================================================================
五、详细信息（右上角）
================================================================

进去以后顶部有两个页：程序、记录。

【程序】页上方有三个视图，切换着看同一批东西：

  · 全部程序   你机器上正在跑的所有程序，可以搜索。
               选中一个（或按住 Ctrl 选多个），底下三个按钮：
                 「结束进程」  现在就把它们关掉，能腾出内存
                 「加入拦截」  以后它一冒头就自动关掉
                 「加入保护」  以后无论如何都不动它
               名字后面带括号的表示受保护，括号里是原因。

  · 已拦截     已经生效的拦截规则，用中文写着"它会拦什么"，
               比如「芒果TV 广告 / 更新 / 迷你页」。
               双击某条可以临时停用，再双击恢复。

  · 已保护     你自己指定"绝对不要动"的程序或目录。
               填程序名（chrome.exe）或安装目录（D:\工作软件）。

【记录】页
  这次运行干过的所有事。红色 = 关掉了谁，绿色 = 释放了多少内存，
  灰色 = 命中了但因为是系统进程而主动跳过。


================================================================
六、几个小问题
================================================================

Q: 会不会误杀我正在用的软件？
A: 不会。规则只针对附属的推广/弹窗进程，不含任何主程序。比如芒果TV 还能正常
   看，只是它偷偷开的推广进程会被关掉。系统进程有四道锁，全部白名单保护。

Q: 为什么豆包 / 微信 / 浏览器这种吃内存的没被清？
A: 故意的。自动回收只碰后台进程，凡是**有可见窗口**的（也就是你正在用的）
   全部跳过。把几 GB 的工作集从正在跑的程序底下抽走，它会立刻疯狂读盘补回来，
   表现就是卡死、白屏、甚至自己重启——看起来就像"被结束进程了"。
   记录里会写「跳过 N 个正在用的程序」，就是这个数。

Q: 我常用的某个软件被误关了怎么办？
A: 打开「详细信息 → 程序 → 全部程序」，找到它，选中，点「加入保护」。

Q: 我想更激进 / 更保守？
A: 打开 config.json（记事本就行）：
     "threshold": 85        改成 75 就更早开始自动清理
     "auto_kill": true      改成 false 就只监控不动手
     "scan_interval": 3     扫描间隔（秒），改小更灵敏
     "trim_cooldown": 120   两次自动清理的最小间隔（秒）
   改完保存，重启程序生效。

Q: 想要开机自启？
A: Win+R 输入 shell:startup 回车，把桌面那个图标复制进去。

Q: 不想要了？
A: 删掉 C:\Users\Henry\MemoryGuard 文件夹和桌面图标即可。
   程序不写注册表、不装服务、不留开机项。
